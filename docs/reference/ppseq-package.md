# ppseq: Design Clinical Trials using Sequential Predictive Probability Monitoring

Functions are available to calibrate designs over a range of posterior
and predictive thresholds, to plot the various design options, and to
obtain the operating characteristics of optimal accuracy and optimal
efficiency designs.
